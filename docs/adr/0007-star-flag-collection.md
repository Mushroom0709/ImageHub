# ADR 0007 — 星标 + 旗标 + 集合：用户手动组织方式

**状态：Accepted** · 2026-08-08

## 背景

系统是纯标签驱动的，没有相册。但用户需要一些手动组织的方式：快速标记好图、做主题精选集等。

## 决策

提供三种手动标记/组织方式，从轻到重：

### 1. 星标 (Star) — 最简标记
- 布尔值：一张图要么星标了要么没有
- 用途：快速标记"好图/喜欢的/想回看的"
- 筛选：顶部一个"只看星标"的开关

### 2. 旗标 (Flag) — 分级标记
- 多级：比如 1-5 颗旗，或者红/黄/绿三色旗
- 用途：标记优先级/处理状态（如"1星=一般，3星=精品，5星=封神"，或"红旗=待修图，黄旗=待分类"）
- 用户可以自定义旗标的含义和颜色

### 3. 集合 (Collection) — 主题精选
- 用户可以创建多个集合（如"西藏旅行参考"、"毕业照姿势"）
- 一个素材可以属于多个集合
- 集合有封面、描述、排序
- 用途：手动挑选的主题合集，类似收藏夹/精选专辑

## 理由

- 三个层级覆盖不同需求：快速标记（星）→ 分级/状态（旗）→ 主题整理（集合）
- 都不影响标签体系，是正交的补充
- MVP 阶段先做星标，旗标和集合后续迭代

## 后果

- assets 表增加 `starred` (bool) 和 `flag_level` (int, nullable) 字段
- 新增 collections 表 + asset_collections 关联表
- 前端：图片卡片上有星标按钮；详情页有旗标和集合操作
- 左侧导航增加"星标"、"旗标"、"集合"入口
