# ADR 0011 — 移动端完整功能适配

**状态：Accepted** · 2026-08-08

## 决策

移动端提供完整功能，不只是浏览。上传、打标、筛选、管理都能在手机上操作。

## 移动端适配要点

- 左侧标签栏改为底部弹出式抽屉（点击标签按钮弹出）
- 瀑布流改为 2-3 列（根据屏幕宽度）
- 多选操作：长按进入多选模式，底部操作栏
- 上传：调用相机 / 相册 / 文件
- 打标：底部弹层，标签分组 Tabs
- 沉浸式视频播放：全屏上下滑动（天然适配移动端）
- 手势：双指缩放、下滑关闭、左右滑动切换图片

## 技术方案

响应式布局（React + Tailwind 的断点系统），不做独立的移动端项目。
一套代码，桌面端和移动端共用。
