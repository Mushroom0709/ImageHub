# ADR 0017 — 实时进度推送：SSE

**状态：Accepted** · 2026-08-08

## 决策

使用 **SSE (Server-Sent Events)** 向前端实时推送上传和采集的进度。

## 适用场景

- 用户上传进度（文件上传状态、缩略图生成、AI 打标进度）
- 小红书链接采集进度（抓取、下载、打标、入库）
- 其他异步任务进度

## 进度数据结构

每个任务（上传任务 / 采集任务）实时推送：
- 任务总数 / 已完成数 / 失败数
- 当前处理项的状态（排队中 / 下载中 / 上传中 / 处理中 / 打标中 / 完成 / 失败）
- 错误信息（失败时）

## 前端展示

- **上传任务**：底部固定进度面板（类似浏览器下载栏），可展开/收起
- **采集任务**：右上角任务卡片 / 或同一进度面板中按类型分组

## 为什么选 SSE 不用 WebSocket

- 只需要服务端→客户端单向推送，SSE 足够
- 实现简单，FastAPI 原生支持
- 自动重连机制
- 没有 WebSocket 的协议复杂度
