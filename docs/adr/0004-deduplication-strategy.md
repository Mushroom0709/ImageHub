# ADR 0004 — 采集两层去重：source_id + 感知哈希

**状态：Accepted** · 2026-08-08

## 背景

采集来的素材需要去重，避免同一张图反复入库。素材的最小单位是单图/单视频。

## 决策

**两层去重**：

1. **第一层（快速去重）**：按 `source_platform + source_id + file_index` 唯一键。同一条笔记的同一张图，重复采集直接跳过。几乎零成本。
2. **第二层（内容去重）**：按**感知哈希 (pHash)**。不同笔记但内容相同的图（比如被多次转发的热门图）也能被识别出来。MVP 阶段可以先不开启，等量大了再加。

## 理由

- 第一层能挡住 90%+ 的重复（同一任务重跑、关键词重叠导致的重复采集）
- 第二层是锦上添花，计算成本略高（需要计算哈希、比对），但能发现跨笔记的重复
- 两层都做，但第二层可开关，MVP 先只开第一层

## 后果

- assets 表增加 `phash` 字段（64 位整数，存感知哈希）
- 唯一索引：`(source_platform, source_id, file_index)`
- 视频去重：用封面帧的 pHash + 时长组合判断
- 第二层去重在采集 worker 中作为可选步骤，默认关闭
