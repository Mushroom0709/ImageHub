# ADR 0015 — 键盘快捷键

**状态：Accepted** · 2026-08-08

## 决策

MVP 阶段实现以下高频快捷键：

| 快捷键 | 功能 |
|---|---|
| `Space` | 预览大图 / 关闭预览 |
| `←` / `→` | 上一张 / 下一张 |
| `1`-`5` | 星级标记（1-5 星）|
| `6`-`0` | 旗标等级（1-5 级）|
| `S` | 切换星标 |
| `Del` / `Backspace` | 删除（移到回收站）|
| `Ctrl+A` / `Cmd+A` | 全选当前列表 |
| `Esc` | 关闭弹窗 / 退出多选 / 取消 |
| `F` | 全屏 / 沉浸式模式 |

## 原则

- 只做高频的，其他按需加
- 遵循常见图库/设计软件的习惯（Eagle、Photoshop、Lightroom）
- 输入框聚焦时不触发全局快捷键
- 移动端不适用（触屏操作）
