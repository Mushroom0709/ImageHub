# ADR 0003 — 删除策略：相册解关联 + 素材软删 15 天

**状态：Accepted** · 2026-08-08

## 背景

两类删除操作的行为：删除相册、删除素材。OBS 对象存储删除后不可恢复。

## 决策

1. **删除相册**：只解除素材与相册的关联，不删除素材本身。被解除关联的素材进入"未分类"状态。
2. **删除素材**：软删除（标记 deleted_at），进入回收站。回收站保留 **15 天**，到期后自动从数据库和 OBS 物理删除。

## 理由

- OBS 删除不可恢复，硬删风险太高
- 相册是组织方式，删除组织方式不应销毁内容
- 15 天足够用户发现误删并恢复，又不会占用太多存储
- 定期清理任务（cron）自动扫描过期的软删素材并清理 OBS

## 后果

- assets 表增加 deleted_at 字段
- 所有查询默认过滤 deleted_at IS NOT NULL
- 需要后台定时任务清理过期软删素材
- 前端需要"回收站"页面，支持恢复和永久删除
