# ADR 0009 — UI 设计方向：图片优先的工具型产品

**状态：Accepted** · 2026-08-08

## 决策

### 整体定位
图片优先的工具型产品——图片是主角，UI 作为画框安静地衬托内容。介于 Eagle（工具效率）和 Pinterest（视觉沉浸）之间。

### 配色
- 主色：Teal（深青 `#0D9488` / 浅青 `#2DD4BF`），专业克制，不与人像图冲突
- 双主题：浅色（`#FAFAFA` 背景）+ 深色（`#0A0A0A` 背景）
- 中性色统一用锌灰阶（zinc），品牌色只用于关键操作和选中态
- 星标：金色 `#F59E0B`；旗标：5 级彩色

### 布局
- 左侧边栏 260px：标签分类树 + 星标/旗标/集合/待审核/回收站入口
- 顶部栏 56px：Logo + 全局搜索 + 上传 + 用户
- 主内容区：瀑布流（4-6 列自适应），间距 12px
- 图片卡片：1:1 缩略图，hover 显示操作按钮

### 字体
- 中文：系统默认（PingFang SC）
- 英文/数字：Inter
- 基准字号 14px，行高 1.5

### 视频体验
- 瀑布流中：滚动到可视区域自动静音播放
- 全屏沉浸式：上下滑动切换（抖音式），右侧浮动信息条

## 理由

- 图库工具的核心是内容，UI 不能抢戏
- Teal 主色在红/黄/蓝的人像图旁边都不会违和
- 高信息密度（14px 字号、紧凑间距）适合工具型产品
- 双视频模式覆盖"快速浏览"和"沉浸式看细节"两种场景

详细设计规范见 `design-system/imagehub/MASTER.md`。
