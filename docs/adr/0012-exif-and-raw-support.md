# ADR 0012 — EXIF 读取 + RAW 预览支持

**状态：Accepted** · 2026-08-08

## 决策

### EXIF 信息
- 上传后自动读取 EXIF 并存入数据库
- 详情页展示关键参数：相机型号、镜头、光圈、快门、ISO、焦距、白平衡、拍摄时间、GPS 定位
- 完整 EXIF 可展开查看
- 工具：`exiftool`（最稳，支持所有格式包括 RAW）

### RAW 支持（ARW 索尼）
- 上传 ARW 文件，自动提取内嵌的预览 JPG 做缩略图和浏览展示
- 原始 ARW 文件保留在 OBS，可下载
- 读取完整 EXIF（相机参数、拍摄信息等）
- 工具：`dcraw` 或 `libraw` 提取预览图

## 理由

用户原片都是索尼 ARW，需要在系统里管理原片。
EXIF 参数是摄影用户的核心需求之一。
