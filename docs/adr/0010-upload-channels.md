# ADR 0010 — 上传方式：全渠道支持

**状态：Accepted** · 2026-08-08

## 决策

支持全部 5 种上传方式：

1. **拖拽上传** — 拖文件到页面任意位置触发
2. **点击选择文件** — 上传按钮打开文件选择器
3. **剪贴板粘贴** — Ctrl+V / Cmd+V 粘贴图片
4. **URL 下载** — 输入图片 URL，后端下载到 OBS
5. **文件夹批量上传** — 拖文件夹或选择文件夹，递归上传所有图片

## 上传流程

预签名 URL 直传 OBS（见 ADR 0008 部署架构）：
1. 前端调 API 申请批量上传凭证
2. 后端生成 OBS 预签名 URL
3. 前端直传 OBS
4. 上传完成回调后端
5. 后端：写入 DB → 生成缩略图 → 读取 EXIF → 计算 pHash → AI 打标（异步）

## 支持的文件格式

- 图片：JPG, PNG, WebP, GIF, BMP, TIFF
- RAW：ARW（索尼）
- 视频：MP4, MOV, WEBM
