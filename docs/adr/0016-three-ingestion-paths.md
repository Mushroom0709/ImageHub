# ADR 0016 — 三种素材来源 & 处理路径

**状态：Accepted** · 2026-08-08

## 决策

系统支持三种素材来源，处理路径各不相同：

### ① 用户上传（自己的原片/成片/视频）
- **触发方**：前端用户操作
- **入口**：拖拽 / 点击选择 / 剪贴板粘贴 / URL 下载 / 文件夹批量上传
- **打标方**：后端 AI（Qwen3.6-27B）异步打标
- **流程**：预签名直传 OBS → 生成缩略图 → 读 EXIF → 算 pHash → AI 打标 → 入库
- **进度展示**：SSE 实时推送，底部上传进度面板

### ② AI 批量导入（外部 AI 采集）
- **触发方**：用户的外部 AI（minimax / deepseek 等）
- **入口**：后端提供"批量导入"API
- **打标方**：外部 AI 自己打好标签，随素材一起传入
- **流程**：外部 AI 调 API → 后端接收元数据 + 文件 → 存 OBS → 生成缩略图 → 算 pHash → 直接写入标签（AI 传入的）→ 入库
- **特点**：后端只负责存储和索引，不做 AI 分析

### ③ 小红书链接采集
- **触发方**：前端用户贴链接
- **入口**：前端输入小红书笔记/视频 URL
- **打标方**：后端 AI（Qwen3.6-27B）
- **流程**：后端调 TikHub 抓详情 → 下载所有图/视频 → 上传 OBS → 生成缩略图 → 算 pHash → AI 结构化打标 → 入库
- **进度展示**：SSE 实时推送，采集任务卡片

## 统一处理流水线

不管哪种来源，所有素材都会经过：
1. 存入 OBS（原图/原视频）
2. 生成缩略图（3 档）
3. 计算 pHash
4. 读取 EXIF（图片才有）
5. 打标签（来源不同，打标方不同）
6. 写入数据库 + 同步到 Meilisearch
