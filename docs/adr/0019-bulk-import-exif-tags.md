# ADR 0019 — 批量导入：文件夹级导入 + EXIF/日期自动标签

**状态：Accepted** · 2026-08-08

## 背景

用户已有 1w+ 张照片（主要是索尼 ARW RAW），按日期文件夹结构存在本地。需要把现有照片全部导入 ImageHub 管理。

## 决策

### 批量导入功能（MVP 必做）
- 支持整个文件夹拖拽导入（递归扫描子文件夹）
- 支持格式：ARW（索尼 RAW）+ JPG/PNG/WebP/TIFF 等常见格式
- 导入流程：扫描文件 → 上传 OBS → 提取预览图 → 生成缩略图 → 读 EXIF → 算 pHash → AI 打标（可选）→ 入库
- 实时进度：SSE 推送，显示总进度 + 当前文件 + 失败列表
- 支持断点续传：刷新页面后可以继续未完成的导入任务

### 自动标签
- **EXIF 信息全部读取并存库**：相机型号、镜头、焦距、光圈、快门、ISO、白平衡、拍摄时间、GPS 等
- **日期自动打标签**：根据 EXIF 拍摄时间自动打 `年份:2024`、`月份:2024-08` 标签
- **相机/镜头自动打标签**：根据 EXIF 自动打 `相机:Sony A7M4`、`镜头:FE 24-70mm F2.8` 等标签
- **焦距自动打标签**：如 `焦段:24mm`、`焦段:广角`（按范围归类）

### 日期标签分类
归入一个新的标签大类：**信息 (info)**，包含：
- 拍摄日期（年/月层级）
- 相机型号
- 镜头型号
- 焦段范围
- 地理位置（如果有 GPS）

## 理由

- 现有 1w+ 张照片必须导入，批量导入是刚需不是锦上添花
- 按日期存的文件夹本身就是一种分类方式，导入后通过 EXIF + 自动标签保留这个维度
- 相机/镜头/焦段标签对摄影师用户非常有价值（"找所有用 85mm 拍的人像"）
