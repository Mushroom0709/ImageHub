# ADR 0013 — pHash 感知哈希用于去重和相似图查找

**状态：Accepted** · 2026-08-08

## 决策

使用 **64 位感知哈希 (pHash)** 作为图片指纹，用于：
1. 采集去重（第二层，内容级去重）
2. 相似图查找功能（"找和这张相似的图"）

## 技术方案

- 算法：pHash（感知哈希，基于 DCT 变换）
- 指纹长度：64 位（BIGINT 存储）
- 相似度判断：汉明距离
  - 距离 < 5：基本是同一张图（不同尺寸/压缩/格式）
  - 距离 < 15：相似图（内容相近，构图微差）
- 存储：assets 表增加 `phash` 字段（BIGINT）
- 计算时机：上传/采集后异步计算

## 为什么不用更高级的方案

- 语义 embedding（CLIP 等）后期需要时再加，MVP 不上
- pHash 实现简单、速度快、存储小，满足当前阶段的去重和简单相似查找需求
