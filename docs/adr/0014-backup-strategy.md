# ADR 0014 — 数据备份策略：数据库每日备份

**状态：Accepted** · 2026-08-08

## 决策

- **数据库**：每日自动全量备份（pg_dump），备份文件存 OBS
- **图片/视频**：依赖 OBS 自身可靠性，不额外备份
- **备份保留**：保留最近 30 天的数据库备份

## 理由

- 数据库是核心（标签、关联、用户、集合等所有结构化数据都在），必须备份
- 图片数据量大，备份成本高（存储和带宽）
- OBS 本身有多副本冗余，丢失概率极低
- 数据库备份很小（几十 MB 到几百 MB），成本可以忽略

## 实现方式

- 定时任务（cron 或 arq schedule）每天凌晨执行 pg_dump
- 压缩后上传到 OBS 的 backup/ 目录
- 自动清理 30 天前的旧备份
