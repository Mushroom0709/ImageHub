## 七、UX 关键准则（来自 ui-ux-pro-max）

- 布局稳定性：aspect-ratio 预留空间，CLS < 0.1
- 图片优化：三档缩略图 + WebP + 懒加载 + srcset
- 移动端：44×44px 最小触控目标，8px 间距，mobile-first
- 可访问性：全键盘可达，焦点环可见，语义化 HTML
- 进度反馈：上传/采集全步骤状态指示，失败可重试
- z-index 层级严格定义（0-60 共 6 层）
- Reduced motion 尊重系统设置
