# Issue tracker — GitHub Issues

## Location

Issues live in the GitHub repository: **Mushroom0709/ImageHub**

Accessed via the `gh` CLI (`gh issue create`, `gh issue list`, etc.).

## Surface

Only issues filed in the GitHub issue tracker are part of the triage queue.

PRs as a request surface: **off**. Pull requests are reviewed through the normal PR workflow, not the triage queue. Flip this flag by changing the line below to `true` if you want PRs to also show up in triage.

prs-in-triage: false
