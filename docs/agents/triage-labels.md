# Triage label vocabulary

The five canonical triage roles, mapped to their label strings in the issue tracker.

| Role | Label string | Description |
|---|---|---|
| needs-triage | `needs-triage` | Newly filed, not yet triaged |
| needs-info | `needs-info` | Needs more information from the filer before it can be worked on |
| ready-for-agent | `ready-for-agent` | Scoped and ready for an agent to pick up |
| ready-for-human | `ready-for-human` | Agent work is done; needs human review or decision |
| wontfix | `wontfix` | Out of scope, declined, or otherwise won't be addressed |

These are the defaults. Edit this file to override individual labels — e.g. if your tracker already uses `bug:triage` instead of `needs-triage`.
