# 11 — 素材 CRUD API + 软删 + 批量操作

**What to build:** 素材的增删改查 API 全通：列表分页、详情、创建、更新、删除（软删）、批量删除、批量恢复、回收站列表。

**Blocked by:** T03-01, T02-03

**Status:** ready-for-agent

## Acceptance criteria

- [ ] GET /api/assets 列表（page/size/sort/sourceType/starred/flagLevel/trashed）
- [ ] GET /api/assets/:id 详情
- [ ] POST /api/assets 创建
- [ ] PUT /api/assets/:id 更新
- [ ] DELETE /api/assets/:id 软删（deleted_at）
- [ ] POST /api/assets/batch-delete 批量软删
- [ ] POST /api/assets/batch-recover 批量恢复
- [ ] GET /api/assets?trashed=true 回收站列表
- [ ] Postman 全部接口可测
