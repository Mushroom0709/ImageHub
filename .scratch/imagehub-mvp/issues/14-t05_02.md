**Blocked by:** T05-01

## Acceptance criteria

- [ ] GET /api/assets/:id/thumb 接口（302 重定向）
- [ ] size 参数：small(300px) / medium(1200px) / raw(原图)
- [ ] 预签名 URL 有效期配置
- [ ] 前端 ThumbImage 组件用 srcset + sizes
- [ ] 浏览器会自动选合适的尺寸
